# coach-offer

Обновлено: 2026-09-06 (вечер, после #136) · ветка: `feat/coach-affiliate-card` — запушена,
мержить можно в любой момент: без env карточки не существует.

## Что это
Фейк-дверь для гипотезы «бандл с карьерным коучем». Идея Игоря (09-06): дать клиентам доступ
к коучам прямо в аппе. Коучинг проводим **не мы** — партнёрская платформа; мы ставим дверь и
меряем клик.

Компонент: `components/dashboard/CoachOffer.tsx`, вставлен под `StatsCards` в
`app/dashboard/page.tsx`.

## Почему именно так (разбор, который стоил разговора)
1. **Созвоны отпали**: исполнителя нет. Игорь их вести не будет (английский + 10 ч/нед потолок +
   расфокус перед запуском), наёмный коуч = отдельный проект на 2 недели. Дверь без исполнителя =
   обман, поэтому вариант закрыт.
2. **«Низкая цена» недостижима**: Strawberry.me = **от $70/нед** (~$303/мес по шкале 52/12)
   против наших **$12/нед / $39/мес** (#136, цены теперь из `lib/pricing.ts`). Коуч дороже
   продукта примерно в **6x** по недельной шкале и в **8x** по месячной — это не бандл, а
   другой бизнес, к которому мы приделали дверь. Поэтому цена партнёра стоит НА карточке до
   клика: если дорого — узнаём это бесплатно.
   (Разговор шёл при старых $9–29 и цифре «10x»; после подорожания вывод не изменился.)
3. **Меряем клик, не покупку.** Покупка происходит у партнёра, мы её не видим (пока нет их
   партнёрской панели). Клик при честной цене = достаточный сигнал для решения «строить дальше».
4. **Response tracking у нас нет** (убит в июньском пивоте, комментарий в `StatsCards.tsx`).
   Изначальный критерий «≥50 заявок И <2 ответов» невыполним — колонки под ответы нет.
   Остался прокси по объёму: `total_applications >= 50`.

## Как включается
Три env-переменные в Vercel (Production + Preview):
- `NEXT_PUBLIC_COACH_URL` — партнёрская ссылка. **Нет её → карточки не существует.** Гейт.
- `NEXT_PUBLIC_COACH_PRICE_NOTE` — честная цена партнёра, дефолт `from $70/week`.
- `NEXT_PUBLIC_COACH_MIN_APPLICATIONS` — порог показа, дефолт `50`.

## Метрики
Vercel Analytics custom events (Hobby → смотреть в дашборде руками, pull-API нет):
`coach_offer_shown` (знаменатель) / `coach_offer_click` (числитель) / `coach_offer_dismissed`.
Решение через 2 недели: **0 кликов на ~30 показов ⇒ гипотеза закрыта**, карточка удаляется.

## Честность — не трогать при «оптимизации»
- цена партнёра видна ДО клика;
- раскрытие партнёрской связи (FTC 16 CFR 255) + `rel="sponsored"`;
- никаких обещаний результата («get hired», «guaranteed interviews») — FTC.
